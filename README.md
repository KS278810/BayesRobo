# BayesRobo

CSVから次に試す条件を提案するベイズ最適化です。インストールは不要で、ブラウザだけで動きます。データは外部に送信されません。

https://ks278810.github.io/BayesRobo/

使い方は、CSVをドロップし、目的を選び、候補をダウンロードします。列は x1, x2, ..., y で、y が空の行が未測定です。「サンプルで試す」で動きを確認できます。
